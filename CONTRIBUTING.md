# Contributing

Thanks for checking out this project! This is a personal portfolio site, so contributions are limited, but here's how to get involved.

## Reporting Issues

Open an issue with:
- What you expected to happen
- What actually happened
- Browser and device info

## Making Changes

1. Fork the repo
2. Create a branch (`git checkout -b fix/your-description`)
3. Make your changes
4. Open index.html in a browser to verify — no build step needed
5. Commit with a clear message
6. Open a PR

## Style

- Keep the Neo-Brutalist × Liquid Glass design direction
- No external JS frameworks (vanilla JS only)
- Test at 375px / 768px / 1440px before submitting
